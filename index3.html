Project 04 · AUTOMATION · COMPLETED

Automatic Chicken Door & Feeder

Designed and built an automatic chicken coop door with a feeder so the chickens could be let out and fed without needing me to get up at 6am. Used parts from an old Meccanoid robot, it connects to my Alexa allowing me to automate it to the time I need the chickens to be let out and fed. Feeder works with a string pulley that releases food in a tube (note I do have to reset it each evening so that would be the next step to work out a way to fully automate it)

Project 05 · PYTHON · COMPLETED

First-Person Car Simulator

Created a simple first-person driving simulator on a Raspberry Pi, displaying a road and landscape on a small screen and using physical inputs to 'drive' the car. This was my first experience working with asynchronous Python programming (was using the Bubus library)

Project 06 · CCTV · COMPLETED

Network CCTV Camera

Built a simple CCTV camera using a Raspberry Pi and camera module. Works by taking loads of pictures continuously (which means the frame rate isn't too good), then can connect to the Raspberry Pi hotspot from another device and view the camera.
